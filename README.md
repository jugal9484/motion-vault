# 🎬 Motion Vault

Welcome to **Motion Vault**, a curated collection of high-end text animations, cinematic effects, and interactive web components. This repository serves as a centralized hub for visually striking frontend experiments ready to be integrated into modern web projects.

---

## 🌟 Featured Animations

### 1. Snowpiercer
A premium, cinematic title splash screen built with HTML, CSS, and GSAP. It features smooth transitions and a dark, immersive aesthetic designed to elevate any landing page or portfolio.

> **🎥 Note:** A preview video demonstrating the final look and feel of the animation is included directly within its respective folder (e.g., `/Snowpiercer/snowpiercer.mp4`).

---

## 🚀 How to Use

Each animation is self-contained within its own directory. To explore or use an animation:

1. Navigate into the specific animation folder.
2. Open the `index.html` file in your preferred web browser to see it in action.
3. **Check the folder for a preview video** to see the intended visual outcome before integrating.
4. Copy the relevant HTML, CSS, and JavaScript into your own project.
